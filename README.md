# URO Phone Recognition Research (L2-ARCTIC)

**Report:** [`report/REPORT.pdf`](report/REPORT.pdf) · data: L2-ARCTIC v5.0 (request from TAMU; not included)

Continuation of David Zuhao Zhang's UBC Undergraduate Research Opportunity project (Jan–May 2024):
how well a zero-shot universal IPA recogniser transcribes non-native English, and whether its errors
track the speaker's first-language phoneme inventory.

| Folder | Contents |
|---|---|
| `phone_recognition.ipynb`, `phone_recognition.py`, `phoible.csv` | Original 2024 URO notebook and scaffold (kept unchanged), and the PHOIBLE 2.0 inventory table |
| `src/common.py` | Speaker→L1 map, stress-aware ARPAbet→IPA, IPA normalisation and segmentation, TextGrid reader |
| `src/inventory_analysis.py` | **Part A**: English target phones vs PHOIBLE L1 inventories (done) |
| `src/run_pfer_experiment.py` | **Part B**: `infer` (wav2vec2 IPA model over L2-ARCTIC) and `analyze` (PER/PFER, per-L1 stats, per-phone errors, H1 permutation test) |
| `src/robustness_check.py` | L1-adjusted H1 test (run after `analyze`) |
| `src/smoke_test.py`, `run_experiment.command` | Model check on this Mac; double-click runner |
| `src/prepare_finetune.py`, `src/finetune.py`, `run_finetune.command` | **Proposed model** (report §6): manifest, accent-robust fine-tuning, predictions |
| `src/compare_models.py` | Zero-shot vs remap vs fine-tuned comparison on unseen speakers & sentences |
| `src/cv_fold.py`, `src/cv_compare.py`, `src/plot_cv.py`, `run_cv.command` | 4-fold speaker cross-validation (report §6.4) |
| `models/ar_w2v2*/` | Fine-tuned model weights, fold 0 and folds 1–3 (1.2 GB each; not in git, created by training) |
| `tests/test_pipeline.py` | Self-checks: file pairing, parsing, alignment, synthetic-effect recovery |
| `results/` | All outputs and figures (final, corrected analysis). Per-utterance prediction files (`predictions*.csv`) are not committed because they contain transcriptions derived from the licensed L2-ARCTIC corpus; they are regenerated by `infer`/`predict`. |
| `report/REPORT.md`, `report/REPORT.pdf` | Research report |

## Run

```bash
python src/inventory_analysis.py --phoible phoible.csv --out results
python tests/test_pipeline.py

# Part B (needs internet, the L2-ARCTIC v5.0 corpus, and ideally a GPU / Apple MPS)
pip install torch transformers librosa panphon pandas scipy matplotlib
python src/run_pfer_experiment.py infer   --l2arctic /path/to/l2arctic_release_v5.0 --out results/predictions.csv
python src/run_pfer_experiment.py analyze --predictions results/predictions.csv --out results
python src/run_pfer_experiment.py analyze --predictions results/predictions.csv --out results --reference perceived
```

The 2024 `outputs.csv` (if found) can be passed to `analyze` directly.
